# Backend de Lomas Eveneser

API de acceso, cuentas y administración de Lomas.

- `npm run dev`: servidor con reinicio automático.
- `npm test`: pruebas automatizadas.
- `npm run db:check`: comprobación de conexión de solo lectura.

Ver [ejecución](../docs/EJECUCION.md) y [acceso](../docs/ACCESO.md).
